SMART SHOPPING INDIA

How to save money when shopping online in India

The cheapest listing is not always the cheapest final price. A useful comparison includes the store sale, coupon, payment offer and only the rewards that are actually eligible.

THE 5-LAYER CHECK

Check these before paying

  1. Store price: start with the actual sale price, not the MRP.
  2. Coupon: check minimum spend, product exclusions and whether the code stacks with the sale.
  3. Bank/card/wallet offer: compare instant discount vs cashback, cap, EMI rules and eligible cards.
  4. Gift card/reward: count it only when it can be used on the same order.
  5. Cashback: treat affiliate or merchant cashback as pending until the transaction is tracked and confirmed.
